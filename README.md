# 红按钮专注钟

给 ADHDer 的番茄钟：一个红色大按钮，按下去专注 25 分钟。

- 到点铃声 + 震动提醒（可切换：铃声 + 震动 / 仅震动 / 静音；震动只在安卓手机上有效）
- 按停止后选择休息 5 分钟或 10 分钟，休息结束自动开始下一个 25 分钟
- 连续完成 4 个 25 分钟，放彩虹糖烟花：恭喜你，已经学习100分钟啦！
- 「我的时间」按天列出学习/工作时长和休息时长
- 记录只存在你自己的浏览器里（localStorage），不上传

在线使用：https://youcyhuang.github.io/red-button-focus/

单文件网页，直接打开 `index.html` 也能用。
